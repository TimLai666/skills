# 依分析目的驗證結果

| 目的 | 驗證重點 |
| --- | --- |
| 描述現況 | 核對分母、單位、缺值與資料涵蓋範圍。加總與來源對得上，不把樣本比例當成全體比例。 |
| 比較或推論 | 確認觀測是否獨立、抽樣與方法假設是否合理。報告差異大小及不確定性，多重比較時處理誤判風險。 |
| 預測 | 依使用情境切分資料，與簡單基準比較。指標反映實際錯誤成本，測試資料不參與補值、特徵選擇或調參。 |
| 分群 | 先確認分群用途，檢查分群穩定性、各群規模與是否可解釋。不要只靠一個分數宣稱分群有效。 |

資料清理沒有固定的最佳做法。缺值可能表示未蒐集、不適用或選擇性缺漏，極端值可能是輸入錯誤，也可能正是研究對象。先辨識原因，再決定保留、標記、修正、排除或補值。無法判定時保留不確定性，檢查處理方式是否影響結論。

例如，預測未來的資料依時間切分，同一人的多筆資料應按評估情境決定是否放在同一組。隨機切分可能讓測試資料與訓練資料過度相似，無法反映實際使用表現。
