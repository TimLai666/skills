# 相關研究與引用關係

需要補充相關論文、引用關係或作者資料時才讀本文件。

以已確認的 arXiv ID 或 DOI 找到 Semantic Scholar 記錄，再依問題查它引用的論文、引用它的論文或推薦結果。先核對題目、作者與編號，避免同名論文或不同版本混淆。

操作、參數及認證需求查 [Semantic Scholar API 文件](https://api.semanticscholar.org/api-docs/) 與 [官方教學](https://www.semanticscholar.org/product/api/tutorial)。部分端點需要 API key，未認證流量共用限制，實際配額依官方文件及帳戶設定。不要假設有 key 就能每秒呼叫 100 次。遇到 429 時依回應降低頻率，無權限時說明限制。

推薦結果與引用量只協助找文獻。納入研究結論前閱讀候選論文，確認它與問題的關聯。需要更廣的文獻搜尋時，依領域搭配其他來源，不將單一資料庫的結果當成完整文獻。
