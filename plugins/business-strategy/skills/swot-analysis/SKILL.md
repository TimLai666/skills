# SWOT Analysis

## Overview

將有證據的優勢（S）、劣勢（W）、機會（O）與威脅（T），轉成可追溯的候選策略，再比較與建議取捨。

預設完成外部因素驗證、內部能力盤點、四象限策略形成與策略選擇。使用者明確只要求分類、檢查某個因素、形成候選或更新局部內容時，依指定範圍交付，沿用適用的既有分析。

## Input Contract

從需求及既有資料確認分析標的、目的、目標市場、比較對象、地區、分析日期與時間視窗。

| 分析層次 | 比較基準 |
| --- | --- |
| 企業 | 同市場的競爭者 |
| 事業單位或部門 | 同細分市場競爭者或提供相同功能的替代方案 |
| 產品或品牌 | 同類別競品 |
| 專案或計畫 | 替代方案及不做的結果 |

缺少會改變因素分類或策略建議的關鍵資訊時才追問。可合理推進的部分說明假設後繼續，缺口只限制受影響的結論。局部任務只補足該部分所需資訊。

## Workflow

### 階段一：驗證外部因素，確認 O 與 T

#### 情況 A：已有 PESTEL 輸入包

承接 pestel-analysis 的「SWOT 輸入包」，核對標的、地區、日期、時間視窗與完整來源記錄。保留機會池、威脅池的原始編號與優先分，將 SWOT 編號對應至來源，例如 `O1 ← EC-02`。

中性因素依本案能力及定位判斷方向。觀察項依重評條件檢查，待查證因素補足依據後才轉為有效 O/T。記錄分類變更的理由，保留原始評分，讓讀者可以核對。

#### 情況 B：其他外部資料或資料不足

已有可核對且適用的市場、顧客、競爭者或產業資料時，承接並補查本案的重要缺口。缺少總體環境證據時使用 pestel-analysis，完成後接續本分析。競爭者與顧客等缺口依實際需要查證。僅要求內部因素檢查時，查閱足以支持比較的資料。

#### O/T 驗證

外部事件與對本案的影響分開說明，來源附日期、連結或文件頁碼。每個因素檢查：

- **機會**：外部變化提供什麼具體利益？現有能力能否掌握，或能否在期限內透過自建、合作、收購等可行方式補足？需要補強時，連結相應 W，記錄資源、時間與成立條件。競爭者也能受益時，評估本案能取得的利益與相對位置。
- **威脅**：在本案時間視窗內，會對成本、營運、目標達成或競爭地位造成什麼具體不利影響？依影響幅度、發生可能性與準備時間判斷優先順序。影響雖在視窗外、但本期就須準備時，說明準備期限與延誤後果，納入本期判斷。
- **狀態**：有依據支持外部因素與本案影響時列為有效 O/T，保留附帶條件。機會尚無可行掌握方式，或因素影響在視窗外且無本期準備需求時，列觀察項並附重評條件。關鍵依據不足時列待查證，說明會改變結論的資料。

同一趨勢可同時帶來利弊，分別記錄影響對象及條件，避免重複計入同一影響。

### 階段二：盤點內部能力，確認 S 與 W

依已確認的比較基準，說明每項能力或限制對本案目標的實際影響。

- **優勢**：以客戶行為、復購、成本、交付品質等證據支持相對優勢，說明如何讓目標客群受益或提高目標達成能力。公司整體績效與個別能力分別查證，避免用整體好壞代替個別證據。
- **劣勢**：以相對差距及具體後果判斷。價格高時檢查顧客願付價格與流失，預算不足時檢查是否限制必要投入，知名度低時檢查目標客群的認識及選擇。定位或資源現況本身不足以決定分類。
- **排序**：優勢依對目標客群或本案目標的重要性、相對競爭者的差異程度排序，標示核心優勢及理由。劣勢依影響與補強需求排序。證據不足的項目標為待查證，無明確利弊的項目可保持中性。

### 階段三：以因素配對形成候選策略

有效因素使用 `S1`、`W1`、`O1`、`T1` 等唯一編號，更新分析時沿用既有編號。每條策略標明來源因素，並說清楚它們如何共同支持該行動。

完整分析檢查以下四種方向，依實質關聯選擇有策略意義的配對。無有效候選的象限說明原因。

| 象限 | 策略方向 | 判斷問題 |
| --- | --- | --- |
| SO | 發揮優勢掌握機會 | 哪項優勢能提高掌握機會的能力或收益？ |
| ST | 運用優勢降低威脅 | 哪項優勢能降低威脅對本案的傷害？ |
| WO | 補強弱點掌握機會 | 透過自建、合作或收購補強後，能否及時掌握機會？ |
| WT | 降低弱點與威脅的共同影響 | 威脅會如何放大弱點？應縮減、退出或降低哪些暴露？ |

例如，假設已有證據支持 `W1：門市覆蓋不足`、`O2：目標地區通路商開放合作且客群相符`，且合作可在期限內完成，可提出 `[W1×O2] 與當地通路商合作，補足目標地區的銷售據點`。合作行動寫在策略中，外部合作條件寫在 O2。

配對之間沒有具體作用關係時略過。多個配對支持同一行動時合併為一條候選，保留所有相關因素編號。待查證因素只能支持附條件的構想，與可供選擇的候選分開呈現。

### 階段四：比較候選並建議主策略

根據核心優勢、弱點及 O/T 的影響與時間，說明整體態勢及較值得關注的方向。態勢判斷以證據為準，不以因素數量決定。

跨象限比較有實質意義的候選。先確認各策略能在必要期限內完成，且投入符合資源限制。無法滿足者列為暫緩或放棄，附理由。對其餘候選，以本 skill 的三項整數評分輔助比較，每項 1–3 分並附依據：

| 維度 | 1 分 | 2 分 | 3 分 |
| --- | --- | --- | --- |
| 可行性 | 需大量投資，但取得資源及執行方式有據可行 | 需小幅補強 | 現有資源即可執行 |
| 影響力 | 對本案目標或競爭地位僅有局部改善 | 有明顯改善 | 改變關鍵營運條件或競爭地位 |
| 時效性 | 可趕上必要期限，但餘裕很小 | 尚有時間，需加速執行 | 執行時間餘裕充足 |

先說明本案如何區分大量／小幅投入及不同影響程度，使用一致基準。時效性衡量能否及時執行及時間餘裕，另交代延誤後果與行動優先順序。

總分為三項相加，範圍 3–9 分。優先比較總分最高的候選，同分時先比較可行性。評分只支持範圍時列出各項上下限及總分範圍。範圍重疊、同分且可行性相同，或關鍵資料不足時，依可查證的目標效益與限制進一步比較，無法區分就保留未定及所需資料。

證據足夠時建議一條主策略，說明相較其他候選的取捨。支援策略須核對共用資源及時程是否相容。零候選或尚無法合理選定時，交代原因與下一步。僅有一個候選時，也須確認它符合目標及限制。支援、暫緩與放棄只列實際存在的項目。

## Output Contract

預設使用繁體中文，以表格與必要說明呈現。完整交付包含：

1. **分析範圍與主要判斷**：標的、目的、比較基準、日期、時間視窗、外部資料涵蓋範圍與重要缺口。
2. **因素記錄**：依 S/W/O/T 整理編號、描述、來源、具體影響、成立條件及排序理由。觀察項、中性與待查證項另標狀態及後續需要的資料。
3. **候選策略與選擇**：每條策略只記錄一次，包含來源因素、行動、投入與期限、評分及理由、建議狀態與取捨。以此表呈現主策略、支援、暫緩及放棄結果。
4. **行動與重評**：依本案安排執行期限、先後順序、觀察指標、審視頻率及觸發重審的條件。

局部交付保留所需證據、理由及限制，只呈現使用者要求的部分。沒有候選或策略尚未選定時，行動以查證或補足條件為主。

## Quality Rules

- S/W 有明確比較基準，O/T 是外部因素，分類可追溯至來源與具體影響。
- 能力可補強的機會、需提前準備的威脅，已依時間與可行性判斷。
- 候選與因素的關係成立，沒有把策略行動當成外部機會。
- 約定範圍內的候選均納入比較，評分可重算，未知資料與未定結論有明確標示。
- 主策略及支援策略符合資源與時間限制，沒有為填滿分類而新增策略。
- 因素、候選及取捨各有一份完整記錄，行動與重評期限符合本案。

分類定義與例子可參考 [University of Arkansas：SWOT Analysis](https://walton.uark.edu/business-communication-lab/resources/business-writing-resources/swot-analysis.php)。本 skill 的評分及交付方式是操作規則。
