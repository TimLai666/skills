# PESTEL Analysis

## Overview

以六個面向檢查外部環境，將有來源的因素轉成具體影響、評分與優先順序，供策略規劃或 SWOT 使用。

預設完成六面向分析、因素評分、有效因素與觀察項整理。使用者明確限定面向、只要求評分或更新既有分析時，依指定範圍交付，沿用可核對且適用的既有資料。

## Input Contract

從需求與上下文確認分析標的、產業、地理範圍、分析目的及時間視窗，並記錄分析日期與時間視窗起訖。

缺少會改變資料選擇或結論的關鍵資訊時才追問。可合理推進的部分，說明假設後繼續；缺口影響的因素標為待查證，列出所需資料。

## Workflow

### 1. 掃描與查證

掃描前閱讀 [六面向掃描與記錄示例](references/scan-and-examples.md)，依本案範圍檢查各面向。候選數量依相關性與證據決定，沒有有效因素的面向說明檢查結果與原因。

| 代碼 | 面向 | 主要判斷 |
| --- | --- | --- |
| P | 政治 | 政策方向、政治穩定、貿易與地緣政治 |
| EC | 經濟 | 景氣、利率、匯率、購買力與資本投入 |
| S | 社會 | 人口、價值觀、生活方式與勞動力 |
| T | 技術 | 技術變化、取得門檻、自動化與替代 |
| EN | 環境 | 氣候、資源、污染與生態影響 |
| L | 法律 | 具體法定義務、權利、執照與執法 |

同一事件依主要影響機制歸入一個面向，註記交叉影響，使用唯一編號。承接既有編號時保留原編號並明示面向；發現重號先建立可追溯的對照。

每個因素記錄可核對的來源名稱、發布或更新日期、連結或文件頁碼。核對資料是否符合本案地區與時間，區分已發生事實、已公布措施與預測。法規須確認適用對象、生效日與目前狀態。

說明因素如何影響本案的成本、市場、競爭、客戶或供應鏈，附幅度依據。來源支持外部事件，公司的影響推估另列計算、假設與限制。

### 2. 評分與篩選

對有足夠依據的候選因素，以整數評定以下三項，逐項附理由。這是本 skill 的排序方法，分數反映分析判斷。

**重要性：因素對本案結構與競爭地位的重要程度。**

| 分數 | 標準 |
| --- | --- |
| 1 | 邊緣影響，可忽略 |
| 2 | 有一定影響但非核心 |
| 3 | 中等重要，需納入規劃 |
| 4 | 高度重要，影響競爭格局 |
| 5 | 決定性重要，不回應將影響生存 |

**影響程度：因素變化對本案的實際衝擊幅度。**

先說明評估期間、比較情境，以及採用營收或哪一項成本作基準。百分比以該基準的變動絕對值計算，機會或威脅另行標記。同一輪使用可比較的口徑；口徑不同時明示差異。

| 分數 | 標準 |
| --- | --- |
| 1 | 幾乎無感，附可忽略的依據 |
| 2 | 已有可辨識的小幅影響，變動小於 5% |
| 3 | 變動達 5%，但小於 15% |
| 4 | 變動達 15%，且不超過 30% |
| 5 | 變動超過 30%，或造成結構性改變 |

幾乎無感的因素先依第 1 級判定。無法換算營收或成本時，以具體營運後果對照影響級別，說明判定依據；結構性改變須指出受影響的營運條件或商業模式。

**時效性：從分析日期到開始產生具體影響的時間。**

| 分數 | 標準 |
| --- | --- |
| 1 | 超過 36 個月 |
| 2 | 超過 12 個月，且不超過 36 個月 |
| 3 | 已在發生，或 12 個月內 |

另註明影響是否落在本案時間視窗。視窗外因素列為觀察項，說明何時重評；若必須在視窗內開始準備，交代準備期限與延誤後果，再評估本期影響。

**優先分 = 重要性 × 影響程度 × 時效性**，最高 75 分。先判斷時間視窗：視窗外因素保留分數並列為觀察項，下列門檻適用於本期因素。

| 優先分 | 分類 |
| --- | --- |
| ≥ 12 | 有效因素 |
| 6–11 | 觀察項，附可觀察的重評條件 |
| ≤ 5 | 排除，簡述理由 |

評分依據只能支持範圍時，列出各項可能分數及優先分上下限。整段落在同一分類時採該分類並保留不確定性；跨門檻時標為待查證，說明哪些資料會改變分類。完全缺乏評分依據時列資料缺口。

### 3. 判斷影響方向

有效因素標為機會傾向、威脅傾向或中性。中性因素須說明哪些公司能力或外部條件會改變方向；同時存在利弊時，分別說明影響對象與條件。

## Output Contract

依使用者要求呈現表格或分項記錄，每個因素只保留一份完整資料，按有效因素、觀察項、排除與待查證分組。可確定分數的因素依優先分排序，範圍重疊時說明排序尚不確定。

完整資料包含：

- 唯一編號、主要面向、交叉影響面向、名稱與現況。
- 來源及可核對的位置。
- 影響對象、作用方式、幅度及依據。
- 影響方向與成立條件。
- 三項評分、理由、優先分或範圍。
- 分類，以及觀察項重評條件、排除理由或待查證缺口。

報告開頭交代分析範圍、日期與主要發現，附約定範圍的掃描結果；僅評分時交代沿用資料的範圍。排除項可縮為編號、分數與理由，詳細證據保留在同份分析的因素記錄。

### 銜接 SWOT 時

當需求包含 SWOT 或由 swot-analysis 呼叫時，交付一份「SWOT 輸入包」：

- 分析標的、產業、地理範圍、分析日期與時間視窗。
- 機會池（O 候選）與威脅池（T 候選）：有效因素的編號、名稱、優先分及影響摘要，依優先分排序。
- 中性因素：編號與方向改變的條件。
- 觀察項：編號與重評條件。
- 待查證因素：編號與缺口，待確認分類後再加入 O／T 候選。

引用完整因素記錄中的來源與評分依據。分開交付時一併附上這些記錄，讓接手者可以核對。交由 swot-analysis 階段一「情況 A」繼續驗證候選因素。

## Quality Rules

- 已覆蓋約定範圍，各面向的掃描結果有據可查。
- 事件、影響推估與假設分清楚，來源符合地區與時間。
- 同一事件的交叉影響可追溯，編號唯一。
- 評分口徑、區間、計算與分類一致，未知資料有明確缺口。
- 影響方向及中性條件具體，觀察項有可追蹤的重評條件。
- SWOT 輸入包符合本次交付需求，候選因素可追溯至完整記錄。
