# 資料查核標準與來源驗證流程

## 查核原則

先讀取並確認資料，再把事實寫進報告。使用者提供的文件、訪談與研究紀錄也可作為來源，須標明性質及適用範圍。

先確認官網、公司全名與業務描述，資料歸屬不明時不能與同名公司的資訊混用。

### 按主張選來源

| 要查的內容 | 適合的來源與核對重點 |
| --- | --- |
| 產品功能、公告、公司立場 | 官網、文件、創辦人公開發文，作為公司說明，必要時以實測核對功能 |
| 成立、融資與投資關係 | 公司及投資方公告、公司登記、媒體或資料庫，核對時間、輪次、金額與對象 |
| 使用體驗與實際成效 | 使用者回饋、獨立測試、原始研究與營運資料，檢查樣本、方法及代表性 |
| 市場規模與產業條件 | 原始報告、統計、協會與監管資料，核對市場定義、期間及計算方法 |

官方來源適合證明公司說過什麼，不能因此壓過相反的實測結果。媒體、投資人與競品評測都要檢查利益關係及是否轉述同一來源，多篇轉載不算獨立佐證。

### 衝突處理

先確認不同來源是否談同一時間、指標與業務。仍有衝突時列出差異，依原始程度、方法及時效說明採信理由。無法判定時保留未定狀態，不強選一方。

## 研究面向清單

完整研究逐項檢視 A–F 六類。局部研究檢視與問題及必要上游相關的面向。每項記錄已查結果、待查缺口或不適用及理由。下列網站是查詢入口，依服務所在地、型態與可取得資料選擇，不把網站存在當成資料完整。

### A 公司基礎資料

- [ ] 官方網站：正式名稱、成立、所在地、核心業務與重要里程碑。
- [ ] 公司資料庫：Crunchbase、PitchBook、Tracxn 或適用的登記、機構資料。
- [ ] LinkedIn Company Page 或公司介紹：員工數、地點、成立資訊，註明數字口徑與日期。
- [ ] 近期媒體報導或公告：確認最新動態。

### B 創辦人與團隊背景

- [ ] LinkedIn、官方簡介、個人網站：每位創辦人的經歷、學歷與本案關係。
- [ ] 若有學術背景，查 Google Scholar 或原始研究紀錄。
- [ ] 媒體訪談：創辦故事與引言，區分本人說明及媒體整理。

### C 資金與投資背景

- [ ] 確認本案是否有外部投資、其他資金來源或相關公開資訊。
- [ ] 投資方官網或介紹：機構性質與和本案相關的背景。
- [ ] 投資公告、新聞稿、投資人聲明：核對實際參與、輪次、金額與時間。
- [ ] 若多份來源轉述同一消息，記錄其共同來源，避免誤判為多方確認。

### D 產品與功能

- [ ] 官網功能介紹與文件：功能、價格或服務條件及版本。
- [ ] App Store、Google Play 或適用的服務平台：功能、更新與使用者回饋。
- [ ] 不同評測或實際使用紀錄：比較功能承諾、完成條件與限制，檢查是否覆蓋關鍵功能。

例如研究虛擬試衣時，應查明服務如何處理身形資訊，以及結果適合視覺搭配還是尺寸判斷，不從展示圖推定技術能力。

### E 市場與競爭

- [ ] 市場規模、成長與行為數據：研究機構報告、行業協會及原始統計。可從 Research and Markets、Statista 等入口追查原資料。
- [ ] 產業特定資料：例如零售退貨可查 NRF、產業協會及相關報導，不要求其他服務套用退貨指標。
- [ ] 具名競爭者與替代方案：用產業資料庫、Product Hunt、產品文件等核對實際服務的需求與市場，不按公司大小或融資狀態直接分類。

### F 外部評價

- [ ] 使用者評論：App Store、Trustpilot、Reddit 或本案相關管道，檢視支持與批評意見及其使用情境。
- [ ] 獨立評測與競品文章：注意測試方法與利益衝突。
- [ ] 相關產業媒體：例如時尚服務可查 Vogue Business、WWD，不要求所有案例都有這些來源。

## 來源標注

正文就近用可核對的連結或編號，標示來源名與資料日期。時間線列事件時間，來源日期另記，不能混為同一日期。

直接引言保留原意，翻譯標明。來源只有摘要或媒體轉述時，用轉述文字，不加引號冒充原話。例如「某創辦人表示……（由某媒體轉述）」。

完整報告末尾統一列出：

```text
[編號]. [來源名]（[資料日期]）— [標題或說明]
[可核對的 URL，或使用者提供的文件名稱與頁碼]
```

每份來源使用一致編號，正文與清單能互相對照。市場數據及研究結果須記錄統計口徑或研究方法。

## 缺資料、時效與推論

- 找不到資料：寫「本次檢索未找到可核對的 [指標] 資料」，必要時說明檢索範圍。只有來源明確證實未公開，才說公司未公開。
- 無法存取：說明受阻的來源與尚待核對的主張，不等同資料不存在。
- 舊資料：列出資料時間，依指標變動速度判斷是否需更新，不把所有超過一年的資料一律視為失效。
- 分析估計：使用可追溯的輸入、方法與假設，清楚標為估計。沒有依據時保留未知。
- Persona 與情緒評分：依 [分析鏈](02-analysis-chain.md) 的對應規格處理，不把推論當成直接觀察。
