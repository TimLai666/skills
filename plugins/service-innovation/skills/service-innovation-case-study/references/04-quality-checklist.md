# 輸出前自我檢查清單

交付前逐項檢查本次範圍。完整報告須覆蓋完整章節，局部研究檢查相關段落與受影響的承接。不適用時說明理由，缺資料或受阻須留下具體缺口，不能勾成已完成。

## 事實與來源

- [ ] 正確識別公司、服務、版本、市場及資料時間，沒有混入同名對象。
- [ ] 每個事實與數字都有可追溯依據。估計與推論說明方法，沒有捏造數字。
- [ ] 引言有說話者、身份、出處與日期，直接引用和轉述區分清楚。
- [ ] 投資方與合作關係逐一核對，任職經歷沒有誤標成技術合作。
- [ ] 時間線事件有來源，日期精度與來源一致，衝突及採信理由有交代。
- [ ] 公司宣稱、獨立測試、使用者回饋與分析判斷明確區分。
- [ ] 缺資料時使用與檢索範圍相符的描述，沒有把存取受阻或未找到當成未公開。

## 分析鏈一致性

- [ ] 完整研究涵蓋生態系、PESTEL、五力、SWOT、策略、STP、BMC、Persona、藍圖與 CJM。
- [ ] 生態系涵蓋本案相關參與者、使用者、具名競爭者與交換，圖例一致，未知關係有文字標示。
- [ ] PESTEL 評分量尺、理由、計算與篩選規則清楚，未採因素及需觀察的風險有交代。
- [ ] 五力分析比較替代方案能取代及無法取代的工作，不只為本產品辯護。
- [ ] SWOT 區分內外部，O/T 可追溯到環境及產業依據，S/W 有公司能力或限制的證據。
- [ ] SO/WO/ST/WT 各類均經檢視，主要策略有比較理由，沒有預設 ST 或其他類型。
- [ ] STP 區隔有市場與需求依據，目標選擇比較環境、競爭與能力，定位和主要方向一致。
- [ ] 課堂模式符合 [區段規格](03-section-specs.md) 的數量、門檻與三軌矩陣，不足處已明確交代，沒有自行改成一般模式。
- [ ] BMC 起點有依據，九格都經檢視，未知數據與待決定方案分開，未固定從關鍵資源開始。
- [ ] BMC 包含差異化策略、驗證實驗與從防禦轉向機會的路徑分析或無法形成的原因。
- [ ] Persona 屬性有來源或明示推論，角色代稱不冒充真人，缺乏依據的屬性沒有硬填。
- [ ] 藍圖呈現五個內容層及三條分界線，前台子層依實際互動，支援包含內外部活動。
- [ ] 藍圖與 CJM 對應同一 Persona 與服務情境，階段及例外能互相對照。
- [ ] 情緒分數有回饋與量尺依據，分析者評分未冒充原始數據，缺資料階段未填中性分數。
- [ ] 真實摩擦與 Aha Moment 的成立條件有依據，未編造正面或批評聲音。
- [ ] 效果區分宣稱、已證實程度與缺口，沒有只列正面結果。
- [ ] 啟發追溯具體分析並說明轉用條件，沒有把單一案例概括為普遍規律。

## 完整報告章節順序

依序核對：

- [ ] 案例名稱
- [ ] 公司背景
- [ ] 創辦人背景
- [ ] 推出這項服務的背景
- [ ] 推出時間（時間線）
- [ ] 推薦原因
- [ ] 應用情境
- [ ] 創新類型（六選一）
- [ ] 創新模式（複選）
- [ ] 產業生態系地圖
- [ ] PESTEL 分析
- [ ] 五力分析
- [ ] SWOT 分析
- [ ] SWOT 碰撞策略
- [ ] 主要策略選擇
- [ ] 鎖定客群（STP）
- [ ] 服務模式 / 商業模式圖（BMC）
- [ ] 顧客 Persona
- [ ] 服務藍圖
- [ ] 顧客旅程地圖（CJM）
- [ ] 創造效果 / 解決問題
- [ ] 相關展示（非必要）
- [ ] 目前成效 / 獲獎情況 / 外部討論關鍵
- [ ] 背後代表的啟發與意義
- [ ] **參考資料（最後，且是唯一的最後區段）**


## 參考資料與交付

- [ ] 正文引用與末尾清單可以互相對照，沒有只在段落出現而漏列的來源。
- [ ] 完整報告有最後且獨立的 `## 參考資料`，按適用類型整理，沒有重複編號或來源。
- [ ] 模板的預填選擇與佔位符已替換，所有圖表與文字結論一致。
- [ ] 圖表格式及引用有效，輸出位置符合工作區與使用者要求。

## 修正方式

- 分析缺少依據：回到 [研究流程](01-research-protocol.md)，取得證據或標明未知，再更新受影響結論。
- Persona 推論不明：依 [分析鏈](02-analysis-chain.md) 的 Persona 規格核對來源與推導，不補造屬性。
- 章節遺漏或順序錯誤：先讀現有文件，精確更新相關段落，保留其他內容並重查引用。依文件規模選工具，不強制使用某種編輯方式。
