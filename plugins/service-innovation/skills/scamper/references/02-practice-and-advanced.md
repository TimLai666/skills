# SCAMPER 實戰演練與進階技法

## 實戰演練：白板擦的 SCAMPER 改造

以下是以白板擦為對象的假設構想，示範提問與改變方式。材料效能與使用效果須經試作確認。

| 維度 | 具體提問 | 構想範例 |
|------|---------|---------|
| S 替代 | 可以替代什麼材料讓它擦得更乾淨？ | 使用特殊化學纖維取代傳統布面 |
| C 合併 | 能與什麼東西合併？ | 在手把中內建清潔噴霧，一體化設計 |
| A 調適 | 可以借用哪種工具處理邊角的方式？ | 借用刮刀的斜角設計，以適應邊角擦拭 |
| M 修改/增加 | 增加什麼零件可以改善它？ | 加裝微型吸塵裝置，減少粉塵飛散 |
| M 修改/外觀 | 改變形狀會讓握感更好嗎？ | 人體工學曲線握把設計 |
| P 他用 | 白板擦還有其他用途嗎？ | 將擦拭結構轉用於螢幕或鏡片清潔，另選不刮傷表面的乾淨材料 |
| E 消除 | 哪些部分可以消除？ | 去掉厚重手把，改為超薄可折疊設計，方便收納 |
| R 重組 | 如何重新組織它的零件？ | 擦拭面改為可撕式多層結構，髒了撕掉一層即換新 |

**操作重點：** 提問要落在具體特點上，再比較改變後是否滿足需求。例如加入噴霧改善清潔，也會增加補充液體與維護工作。

## 進階技法：自然類比（Form and Function Analogy）

需要從其他領域尋找機制時，可將 SCAMPER 與「形式與功能類比」結合。

**操作方法：** 觀察生物構造，辨識它在特定環境中發揮的功能，再把機制轉成設計假設。比較材料、尺度與環境差異，確認哪些條件能轉用。

**形式與功能對照示例（用於類比發想，不作為發明起源的認定）：**
- 玫瑰刺（防禦採食）→ 有刺鐵絲網（區域管制與防護）
- 蓮葉表面微結構（疏水排污）→ 防汙衣物與建築外牆塗層
- 鯊魚皮紋理（減少水阻）→ 競技泳衣設計

**研究參考：** [Hussain 與 Carignan（2016）](https://scholarworks.uni.edu/journal-stem-arts/vol1/iss2/6/) 讓 24 位小學四年級學生輪流使用一般 SCAMPER 與結合動物適應類比的方式。在這項受限材料實驗中，類比條件的發明評分較高（p=.003，Cohen’s d=0.64），作品呈現較高複雜性與原創性，但一般條件的圖表填寫評分較高。這是特定教學情境的結果，不能推論所有創新任務都應增加難度，也不能僅由評分推定認知負荷的因果關係。

**初學者建議的 3 個自然類比方向：**

1. **生存防禦機制**
   觀察刺蝟或犰狳的外部結構 → 應用於保護性包裝設計或防撞結構

2. **捕食與附著**
   觀察蜘蛛網的黏著性 → 啟發新型過濾器、黏性固定裝置或暫存系統

3. **環境適應與偽裝**
   借鏡變色龍的變色原理 → 設計能隨環境調整外觀的材料或介面

## 受限材料下的 SCAMPER 應用

可用材料受限時（如紙杯、吸管、鋁箔紙、迴紋針），從材料特徵尋找能滿足功能的組合。

**操作原則：**
- 受限不是障礙，而是「形式轉化」的觸媒
- 依本次探索範圍，逐一檢視每種材料在各維度的可能性
- 重點在「這個材料的形式能解決什麼功能需求」的跨域連結

**實作步驟：**
1. 列出所有可用材料
2. 對每種材料提問「它的形式特徵是什麼？」（硬度、彈性、透明度、導電性...）
3. 對應 SCAMPER 維度，思考這些形式特徵可以服務於哪些功能
4. 組合多種材料的構想，形成可行方案

## 教育應用：創意寫作中的 SCAMPER（以《灰姑娘》為例）

SCAMPER 也可用於文學分析與創意寫作，培養多角度思考與批判性視角：

| 維度 | 引導提問 | 教學目標 |
|------|---------|---------|
| S 替代 | 如果灰姑娘的角色被設定為男孩會發生什麼？ | 探討性別刻板印象與角色轉換 |
| A 調整 | 如果場景移到現代東京的科技公司，情節如何演變？ | 考察跨時空背景的邏輯一致性 |
| R 逆向 | 如果繼母實際上是保護灰姑娘的正面人物？ | 培養同理心與多角度批判視角 |
| P 他用 | 如果把《灰姑娘》改成討論職場資源分配的角色扮演教材？ | 將故事轉用於新的學習目的 |
| E 消除 | 如果故事中完全沒有魔法，灰姑娘如何靠自己改變命運？ | 強化現實主義敘事能力 |
| R 逆向 | 如果故事從結局開始，透過閃回尋找真相？ | 訓練非線性敘事結構 |

---

## 演練回顧

檢查提問是否指出具體特點、類比機制能否轉用，以及材料限制對方案的影響。用試作與同儕回饋修正構想，保留能改善功能的部分，刪除只增加操作負擔的設計。
