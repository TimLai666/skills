# 多語言思考

## 主題定位

多語言思考層讓同一個決策單元在六種語言中各自形成完整分析，再比較各條路徑的結論。它不依題目涉及哪個國家、市場、法域、資料來源或受眾選語言。

每個決策單元固定使用英文、西班牙文、德文、現代標準阿拉伯文、韓文與土耳其文。繁體中文保留使用者原始問題並負責統整，不算第七條分析路徑。

## 固定六語

六條路徑都要回答完整任務。下表只規定各路徑完成完整分析後，還必須檢查的資訊。

| 語言 | 固定注意方向 | 必須回答的檢查問題 |
| --- | --- | --- |
| 英文 | 施事者、因果與作用機制 | 誰或什麼造成結果？經過什麼機制？哪個變數可以控制？ |
| 西班牙文 | 事件、意外性、情境與結果 | 行為是否出於故意？環境與流程如何促成事件？結果本身是什麼？ |
| 德文 | 終點、目標與完成狀態 | 最後要抵達什麼狀態？完成如何驗收？哪些條件仍未滿足？ |
| 現代標準阿拉伯文 | 過程、進行中狀態與轉變 | 事情目前在哪個階段？正在如何變化？抵達終點前可能轉向哪裡？ |
| 韓文 | 緊密／鬆散、接合與相容條件 | 各部分如何接合？介面、依賴與限制是否匹配？哪裡太緊或太鬆？ |
| 土耳其文 | 親見、推論、轉述與確定程度 | 每項主張從哪裡得知？哪些是觀察、推論或轉述？不確定性多大？ |

英文與西班牙文形成「施事歸因／事件情境」對照。德文與現代標準阿拉伯文形成「終點／過程」對照。韓文負責檢查組件是否契合，土耳其文負責檢查結論的資訊來源。

## 與資料及輸出語言分工

語言在任務中有三種不同用途，不得混在同一個路由：

| 用途 | 決定方式 | 是否算多語言思考路徑 |
| --- | --- | --- |
| 思考語言 | 固定六語 | 是 |
| 資料語言 | 原始資料使用什麼語言，就以該語言查閱並核對 | 否 |
| 輸出語言 | 依使用者或受眾要求決定 | 否 |

日本市場、德國法規或法文訪談只會影響資料查閱與交付方式，不得改變固定六語。資料語言剛好也是固定六語之一時，仍只有一條該語言的思考路徑，不能重複計數。

## 隔離執行

1. **建立共同任務包** — 只放使用者原始問題、必要背景、已查證資料與限制。不要加入主 agent 的預設答案。原始問題保持原文，避免翻譯先改變需求。
2. **使用指定語言分析** — 每條路徑都從共同任務包開始，以自己的語言完成全部分析與固定檢查。不得先產出一份繁中或英文答案，再翻成其他語言。
3. **隔離各條路徑** — subagent 可用時，每種語言使用獨立 context。可用名額不足時分批執行，每個 subagent 仍只能取得共同任務包與自己的語言指令。
4. **沒有 subagent 時依序重跑** — 主 agent 依英文、西班牙文、德文、現代標準阿拉伯文、韓文、土耳其文的順序執行。開始下一條路徑前重新讀共同任務包，不引用已完成路徑的內容。

## 繁體中文彙整

六條路徑完成後，主 agent 才能開始彙整：

1. **比較施事與事件** — 對照英文與西班牙文是否對責任、意圖、環境及結果提出不同解釋。
2. **比較終點與過程** — 對照德文與現代標準阿拉伯文是否忽略完成條件或中途變化。
3. **檢查契合度** — 納入韓文路徑找到的介面、依賴、限制與鬆緊問題。
4. **檢查證據來源** — 依土耳其文路徑把事實、觀察、推論、轉述與未知分開。
5. **交給後續思考** — 保留會影響後續判斷的共同結論、實質衝突、獨有發現與待查證事實，不裁決哪條路徑正確，也不形成最終判斷。

共同結論只代表多條路徑提出相同判斷，不代表事實已經查證。共用層要把六語分析中會影響判斷的內容與選中任務類別的筆記一起跑過思維模型、謬誤檢核與減法審查，再形成最終判斷。六條路徑可能共享訓練偏誤，也可能一起犯錯；路徑數量不是信心分數。

## 自檢清單

- [ ] 六條固定語言路徑都實際完成，沒有任何一條被繁中角色扮演或同語言提示取代
- [ ] 每條路徑都回答完整任務，並回答自己負責的檢查問題
- [ ] 每條路徑使用指定語言，沒有翻譯或沿用其他路徑
- [ ] 國家、市場、法域、資料來源與受眾沒有改變固定思考語言
- [ ] 資料語言與輸出語言沒有被算成額外思考路徑
- [ ] subagent 名額不足時採分批隔離執行，沒有讓路徑互相看見
- [ ] 彙整比較了施事／事件、終點／過程、契合度與證據來源
- [ ] 六語分析保留了會影響後續判斷的共同結論、衝突、獨有發現與待查證事實，沒有提前形成最終判斷
- [ ] 共用層已把六語分析中會影響判斷的內容納入後續思考，再形成最終判斷
- [ ] 沒有把多數票當成事實證明
- [ ] 最終交付使用繁體中文，除非使用者指定其他語言
