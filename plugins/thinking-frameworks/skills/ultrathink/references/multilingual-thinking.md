# 多語言思考

## 啟用條件

已有可核對的資料，但對其解釋、推導或重要取捨有實質分歧，且獨立複核可能改變判斷時，自動啟用。缺口是可查事實時，先查資料或實驗。使用者明確要求六語分析時也啟用，缺資料的主張保留待驗證。翻譯或指定輸出語言本身不是啟用依據。

## 主題定位

多語言思考層讓同一個決策單元在六種語言中各自形成完整分析，再比較各條路徑的結論。它不依題目涉及哪個國家、市場、法域、資料來源或受眾選語言。

每個決策單元固定使用英文、西班牙文、德文、現代標準阿拉伯文、韓文與土耳其文。繁體中文保留使用者原始問題並負責統整，不算第七條分析路徑。

## 固定六語

六條路徑各自用指定語言完整分析同一問題，自行形成切入點、辨識假設並檢查反例。不預先分配角色、觀點或固定檢查方向，也不預設不同語言必然得出不同結論。

## 與資料及輸出語言分工

語言在任務中有三種不同用途，不得混在同一個路由：

| 用途 | 決定方式 | 是否算多語言思考路徑 |
| --- | --- | --- |
| 思考語言 | 固定六語 | 是 |
| 資料語言 | 原始資料使用什麼語言，就以該語言查閱並核對 | 否 |
| 輸出語言 | 依使用者或受眾要求決定 | 否 |

日本市場、德國法規或法文訪談只會影響資料查閱與交付方式，不得改變固定六語。資料語言剛好也是固定六語之一時，仍只有一條該語言的思考路徑，不能重複計數。

## 隔離執行

1. **建立共同任務包** — 放入使用者原始問題、必要背景、已查證資料及來源、限制與待驗證假設。提供可查閱的檔案或外部資料入口，不加入主 agent 的預設答案。原始問題保持原文。
2. **使用指定語言分析** — 每條路徑都從共同任務包開始，以自己的語言完成分析，可自行查閱原始內容、外部研究與實作。回傳重要主張的來源、適用條件、推論及未解疑點。不得先產出一份答案，再翻成其他語言。
3. **隔離各條路徑** — subagent 可用時，每種語言使用獨立 context。名額不足時分批執行，各自取得共同任務包、語言指令與自行查得的資料，不讀取其他路徑的分析。
4. **沒有 subagent 時** — 可在同一對話依序完成六語分析，但必須說明它們共用上下文，不宣稱彼此隔離。若使用者要求嚴格隔離，回報環境限制，不以同一對話的重跑冒充。

## 繁體中文彙整

六條路徑完成後，主 agent 才能開始彙整：

1. **比較各條路徑** — 整理共同結論、不同切入點、隱含假設、反例與獨有發現，不按語言預設貢獻。
2. **辨識實質分歧** — 分清用詞差異與會改變建議的差異，保留各自證據及待查事項，暫不以共識裁決。

共同結論只代表多條路徑提出相同判斷，不代表事實已經查證。主 agent 核對會影響結論的主張與分歧，必要時查資料或選用相關工具，再形成最終建議。六條路徑可能共享偏誤，也可能一起犯錯；路徑數量不是信心分數。

彙整時合併重複來源與轉述，區分新增證據、不同推導與文字差異。資料缺口改由查證或實驗處理。只有具體新疑點需要獨立複核時才追加分析，不為增加共識重跑六語。

## 自檢清單

- [ ] 六條固定語言路徑都實際完成，沒有任何一條被繁中角色扮演或同語言提示取代
- [ ] 每條路徑都回答完整任務，沒有被預先指定角色或觀點
- [ ] 每條路徑使用指定語言，沒有翻譯或沿用其他路徑
- [ ] 重要主張能對照來源，推論與假設有區分，沒有把共同資料計為六份獨立證據
- [ ] 國家、市場、法域、資料來源與受眾沒有改變固定思考語言
- [ ] 資料語言與輸出語言沒有被算成額外思考路徑
- [ ] subagent 名額不足時採分批隔離執行，沒有讓路徑互相看見
- [ ] 彙整比較了各路徑實際提出的切入點、假設、反例與證據
- [ ] 六語分析保留了會影響後續判斷的共同結論、衝突、獨有發現與待查證事實，沒有提前形成最終判斷
- [ ] 主 agent 已核對影響判斷的主張與分歧，再形成最終建議
- [ ] 沒有把多數票當成事實證明
- [ ] 最終交付使用繁體中文，除非使用者指定其他語言
