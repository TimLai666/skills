# Word 報告版面

製作 Word 時讀取本文件。頁面方向、分節與欄寬的 API 依實際使用的文件工具設定。

## 屬性目錄

直式頁面，欄位為編號、屬性、評估定義、Maslow 需求層級。證據引文與來源可接在目錄後，保持編號可對照。

使用一致字型與清楚的表頭。需求層級可用不同底色，未判定者標示「未判定」。不要為了湊齊層級增加屬性。

## 產品評分矩陣

橫式頁面，欄位為編號、屬性、各產品分數、屬性平均。產品標題下列出非空白評論數。跨頁重複表頭，保持固定目錄順序。

| 數值 | 顯示方式 |
| --- | --- |
| 0–4 | 紅色系，保留數字 |
| 5 | 黃色系 |
| 6–7 | 淺綠色 |
| 8–10 | 深綠色，文字保持可辨識 |
| null | 灰底「—」，圖例註明無可判定評價 |

表前列出色彩圖例。平均顯示兩位小數，旁邊標示有效數／總數。全空值顯示「—（0/總數）」。顯示用的破折號不能回填成計算資料。

表底分開列出「已評屬性平均」與「共同屬性平均」。共同屬性平均只在可排名時顯示，附上共同屬性清單及占目錄的比例。無法排名時用文字說明原因，保留原有產品欄。

產品欄過多時分成多張表，重複屬性編號與必要表頭，不以過小字體塞進單頁。層級分隔帶只用於原目錄已按層級分組的情況。

## 文件檢查

- 表格與儲存格都設定一致的絕對欄寬，總寬不超過頁面可用寬度。
- 底色用清晰填色設定，避免 solid 遮住內容。文字換行使用段落或工具的換行元素。
- 實際渲染檢查直橫式分節、跨頁表頭、文字裁切、數值與底色。頁面尺寸的傳入方式依工具 API，不套用其他函式庫的方向規則。
- 核對表格與摘要均使用同一份彙總結果。檔案成功產生但無法渲染時，交代尚未完成視覺檢查。
