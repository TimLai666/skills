# 評論與屬性探索

## 用途

評論補充使用情境、需求與候選屬性。商品規格提供可編碼的實際值。交叉檢查
兩者可以改善屬性定義，但評論沒有提到的屬性不必然不重要。

## 整理流程

1. 依研究範圍取得可使用的評論，保留來源、評論 ID、商品 ID 與期間。
2. 處理重複或明顯無關資料，保留排除依據。短評論也可能包含明確需求，
   不固定依字數刪除。否定詞、情境與原文引句要保留。
3. 依資料量選擇人工編碼、模型輔助或關鍵詞整理，抽查原文以確認分類。
4. 同一評論對同一主題只計一次；分開報告提及次數、正負感受與適用情境。
5. 對照商品實際屬性，記錄保留、排除或待確認的理由。

可交付「主題／提及數與分母／情境與感受／原文來源／對應商品屬性」表。
理論框架只在有助於當前研究時使用，不固定套 Maslow 或其他分類。

## 解讀限制

- 提及頻率是這批評論的內容分布，不是購買偏好係數或市場需求比例。
- 評論者不等於全體顧客，取得評論的方式可能影響觀察結果。
- 負面提及可能來自品質問題，不能直接解讀成顧客不需要該功能。
- 評論對應商品若作為選擇代理，另需處理可選集合、曝光與選擇事件等資訊。
- 研究問題有理由納入但評論少見的屬性，先檢查實際值與資料支持，不機械排除。
