# 情緒曲線呈現

產圖時閱讀共同規格，再依輸出格式閱讀對應段落。情緒分數與原因依 [情緒評分與示例](emotion-scoring.md)。

## 共同規格

階段數 N、階段順序、分數、文字與表格共用同一份資料。N 須至少為 1，欄寬為正數，分數須在 1–5 或明確缺值。單一階段只畫一個點，未知分數留缺口，不跨缺口連線。

曲線區只涵蓋階段欄，不含左側「項目」欄。設各階段欄寬為 w1…wN，總寬 W 為欄寬總和。第 i 點位於前面所有欄寬總和加 wi/2，分隔線位於累積欄寬。等寬時可用 xlim=[0,N]、點位 0.5…N−0.5，分隔線 1…N−1。

- 基準線 y=3，虛線且不顯示資料點。
- 分數小於 3 用紅色 `#E24B4A`，3 至小於 4 用琥珀色 `#BA7517`，4 以上用綠色 `#3B6D11`。
- 曲線與基準線之間，上方填藍色 `#378ADD`、下方填紅色 `#E24B4A`，透明度 0.20。
- 背景 `#F0F7FF`，階段分隔線為垂直點線，隱藏座標軸、刻度及外框。
- 點上方顯示同色粗體分數，保留上下空間以免 1 分或 5 分標籤被裁切。
- 情緒文字列維持各階段獨立儲存格及原階段底色。明細加分用綠色、減分用紅色，仍保留正負符號及文字，避免僅靠顏色區分。

## Word

依實際頁面與表格寬度決定階段欄寬，使用固定欄寬，關閉自動縮放。圖像儲存格合併 N 個階段欄，內距設為零，左側項目格保持獨立。圖下方情緒文字列有 N 個獨立階段格。

可用 matplotlib 產出 PNG。若 W 與圖高 H 以 pt 表示，`figsize=(W/72,H/72)`。H 依可讀性設定，例如 90 pt，產圖及嵌入維持相同長寬比例。圖區占滿水平範圍，在圖內用 y 軸範圍預留標籤空間。使用 `subplots_adjust(left=0,right=1,top=1,bottom=0)`，固定畫布儲存，停用 tight bounding box 裁切，以免改變圖像寬度與點位。

嵌入時依所用文件工具的實際單位換算，明確設定圖像寬度 W 並等比例縮放。pt、像素與文件長度單位分開處理，不將繪圖尺寸直接當成某個函式庫的影像參數。確認合併格的實際寬度與圖像寬度一致，圖像段落無額外水平縮排。

渲染文件後核對點位是否在各欄中心、分隔線是否對齊欄框，以及比例、中文字與分數標籤是否正常。

## 網頁與可執行圖表的聊天介面

可用 Chart.js 等支援的圖表工具。階段標籤與基準線陣列都依 N 建立。將曲線放在跨 N 欄的區域，點位依共同規格的實際欄寬計算，使用數值 x 軸可支援不等寬欄位。

隱藏座標軸並移除水平圖區內距，基準線無點，分數點與標籤保留。曲線採線性連接，避免平滑插值產生超過 1–5 的波峰。填色以 y=3 為分界，缺值不連線，明細表放在旅程表下方。圖例標示分數意義與資料來源性質。

視窗尺寸改變後依實際欄寬重新定位。檢查最窄預期畫面及不同階段數，確認文字可讀且曲線與欄位對齊。

## 純 Markdown

純 Markdown 表格不能合併階段欄或執行 Chart.js。情緒曲線列逐欄放對應分數，下一列放情緒文字，另附明細。保留 `＋`、`－` 與數值，無法呈現文字顏色時使用一般文字。

使用者明確要求曲線圖時，另附可顯示的圖像，或以支援的網頁／文件格式呈現。圖像無法精確對齊 Markdown 欄位時說明限制，不用箭頭儲存格冒充連續曲線。
