# 情緒評分與示例

製作或修改 CJM 情緒分數時閱讀本文件。評分與曲線依實際階段數處理。

## 評分依據

先說明分數是分析推估或來自顧客研究。推估因素須對應接觸點與情境，逐項列出加減幅度及理由，同一輪採一致尺度。因素與幅度由本案證據支持，不能因產品陌生就預設負分，也不能為品牌形象調高分數。

研究直接提供的評分保留原量尺、來源與統計口徑，不反推虛構加減因子。需要換算成 1–5 分時先說明換算方法。不同口徑的資料分開標示，無法合理比較時不要連成同一條曲線。

## 推估算式

每個階段獨立以 3 分（中性）起算：

`情緒分數 = max(1, min(5, 3 + 加分幅度總和 − 減分幅度總和))`

加減幅度以正數記錄，允許小數。每項因素附幅度，不能只列因素數量。先保留原始合計，再將超出 1–5 的結果限制在範圍內，明示有套用上下限。資料不足不等於中性，無法估計時標待查證並在曲線留缺口。

| 可能加分的情境 | 可能減分的情境 |
| --- | --- |
| 接觸可信的朋友推薦或評價 | 對品類的負面印象或陌生感造成顧慮 |
| 試用或示範帶來具體價值 | 價格與價值疑慮尚未解決 |
| 省下時間或減少操作錯誤 | 擔心犯錯、資料遺失或學習成本 |
| 意外解決原先未提出的困難 | 使用後仍需手動修正或遇到部分失敗 |
| 持續服務與交接累積信任 | 信任或服務連續性受損 |

這些是判斷線索，實際反應與幅度須依本案，不是每次都要套用的清單。

## 明細與關鍵時刻

在旅程表後列出 `階段 | 情緒分數 | 加分原因 | 減分原因`。分數加粗並置中，各因素獨立換行，分別以 `＋`、`－` 開頭。確實無因子時寫 `（無）`，未知則標待查證。研究直接提供的分數，在原因欄寫觀察到的原因或「未提供因子拆解」，不湊算式。

對同口徑且有分數的相鄰階段計算後者減前者。最大正向差值可標為「最大情緒改善」，並列就列出並列階段。持平、全程下降、僅一階段或跨缺值時，不指定沒有依據的跳升。

Aha Moment 指顧客體認產品或服務價值的時刻，須由具體行為、回饋或情境支持。最大情緒改善只是檢查線索，折扣降低顧慮未必是體認核心價值。證據不足時保留待驗證，不強行指定。

## 假設示例

假設客群是忙碌上班族，重視健康但沒時間準備午餐，正在考慮健康便當訂閱。以下服務條件與顧客反應均為示範假設，分數是分析推估。

| 階段 | 情緒分數 | 加分原因 | 減分原因 |
| --- | :---: | --- | --- |
| 認知 | **2 分** | （無） | －0.5 不確定訂閱是否划算<br>－0.5 擔心口味踩雷 |
| 考慮/研究 | **3 分** | ＋0.5 朋友有在訂、評價不錯 | －0.5 試吃門檻高，怕浪費錢 |
| 決策/購買 | **4.5 分** | ＋1 首週折扣降低試錯成本<br>＋0.5 退訂容易降低風險感 | （無） |
| 使用 | **4.5 分** | ＋1 餐點準時到、份量足<br>＋0.5 減少外食煩惱 | （無） |
| 關係建立 | **4 分** | ＋0.5 每週菜單有變化不膩<br>＋0.5 推薦給同事獲得認同感 | （無） |

相鄰差值為 +1、+1.5、0、−0.5。最大情緒改善在考慮/研究到決策/購買，原因是試錯顧慮降低。是否已體認便當訂閱的核心價值，需要進一步顧客回饋。
