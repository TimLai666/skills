# 執行檢查、衡量與交付模板

提出可執行活動方案前讀執行檢查；評估成效或交付完整方案時讀衡量與對應模板；需要其他技能深入協助時讀分工表。

## 七大執行地雷（避免清單）

| 地雷 | 說明 |
|------|------|
| 過度計畫 | 過於僵化無法即時回應機會 |
| 後續聯繫中斷 | 目標需要追蹤或再行銷，卻未安排自願留資料與後續聯繫 |
| 行動路徑中斷 | 有注意與參與，卻缺少符合目標的下一步 |
| 閉門造車 | 缺乏受眾調查，創意淪為自嗨 |
| 語氣僵硬 | 文案缺乏人味，無法引起共鳴 |
| 不懂反覆利用 | 只做一次曝光，浪費創意投資 |
| 目標脫節 | 活動吸睛，但沒有推進原定的認知、體驗或銷售目標 |

## 成效衡量

依主目標選指標，並交代定義、資料來源、統計期間與比較基準。目標值與預估須標明假設，不能當成已發生成果。

| 目標 | 可選指標 | 使用方式 |
| --- | --- | --- |
| 認知與觸及 | 觸及人數、曝光次數、每千次曝光成本（CPM） | 分清人數與次數，說明現場與線上資料是否重複 |
| 體驗與互動 | 參與人數、完成率、停留時間、留言／分享、活動後回饋 | 依互動設計選取，不能只用曝光推論共鳴 |
| 後續行動 | 點擊率（CTR）、試用／兌換／購買轉換率（CVR）、每次行動成本（CPA） | 說明分母與追蹤方式，連回活動目標 |
| 收益 | 廣告投資報酬率（ROAS）、投資報酬率（ROI） | ROAS 衡量廣告費對營收，ROI 要交代收益與完整成本的計算範圍 |

## 活動設計模板

依使用者要求的深度交付，完整方案可涵蓋：

1. 目標與受眾：希望誰產生什麼改變，成功如何判斷。
2. 核心創意與場域：為何會吸引這群人，與品牌或產品有何關係。
3. 參與動線：如何注意、加入、體驗、離開與採取下一步。
4. 體驗模組與 5E：選擇理由，各環節如何支撐目標；有影響的缺口如何處理。
5. 執行安排：人力、物料、預算、時程、場地許可、現場容量與備案。
6. 後續行動與素材延伸：依目標安排分享、試用、購買或自願留下聯繫方式。
7. 成效衡量：主指標、取得方式、比較基準及評估時間。

只要求創意方向時，交付創意、參與方式、選擇理由與關鍵可行性限制，不另補一份完整活動企劃。

## 現有案例分析模板

1. 說明已觀察到的活動做法與來源。
2. 識別游擊手法、SCHMITT 模組及其主次作用。
3. 檢視 5E 各環節與目標的關係，判斷缺口是否影響效果。
4. 分析活動如何推進認知、記憶或後續行動。
5. 分開列出已公布成果與建議追蹤的指標，再提出可借用的機制及適用條件。

## 與其他 Skill 的搭配建議

| 搭配 Skill | 搭配時機 |
|-----------|---------|
| `sor-marketing-strategy` | 深化 S-O-R 消費者心理分析，細化刺激設計 |
| `customer-persona-framer` | 受眾不明或彼此矛盾，需深入釐清才能選場域與體驗模組 |
| `customer-journey-mapper` | 把 5E 閉環對應到 CJM 各觸點，找出體驗落差 |
| `maslow-five-needs-marketing` | 將 SCHMITT Feel/Relate 模組升級為馬斯洛情感訴求層次 |
| `scamper` | 用 SCAMPER 對游擊創意進行系統化激盪與反轉 |
| `service-design-workshop` | 把線下體驗活動服務化，設計完整前台後台流程 |
| `psychological-trigger-marketing` | 在游擊事件加入 FOMO、錨定、框架等心理觸發器 |
| `bcg-growth-share-matrix` | 評估品牌組合中哪些產品適合游擊 vs 體驗行銷投資 |

以上分工依任務需要選用，提供受眾、目標、場域與資源限制，取得結果後整合回活動方案。
