# 09｜品牌語氣設計

> 寫 1 篇貼文要會抓 Hook。寫 100 篇貼文需要的是品牌語氣系統。

## 為什麼語氣決定長期經營成敗

讀者追蹤一個帳號，不只是因為某篇貼文有趣，而是因為**這個帳號的語氣讓他覺得有連結**。

```
單篇爆文 → 觸及大量陌生人
品牌語氣 → 把陌生人轉換成追蹤者
```

語氣一致可幫助讀者辨識帳號，但追蹤仍取決於內容價值、受眾與持續表現。

## 品牌語氣的 5 個維度

### 1. 距離感（Formal ↔ Casual）

```
正式：「我們認為行銷的本質在於...」
親密：「我們最近想了一件事...」
口語：「老實說啦，行銷其實就是...」
廢話：「欸欸欸你聽我說，這件事真的...」
```

Threads 的甜蜜點：**親密 ↔ 口語之間**。太正式像政府網站，太廢話像 Dcard。

### 2. 銳利度（Soft ↔ Sharp）

```
柔和：「也許每個人的選擇都有他的道理。」
中立：「這件事其實沒有標準答案。」
銳利：「不選擇本身就是一種選擇。」
攻擊：「不選擇的人，活該被生活選擇。」
```

可嘗試的方向：**中立 ↔ 銳利之間**。

### 3. 自信度（Humble ↔ Confident）

```
謙遜：「我可能不是最懂的人，但我覺得...」
平和：「分享一下我的觀察。」
自信：「我跟你說，這件事就是這樣。」
高傲：「不要再說行銷很簡單了，沒讀過的閉嘴。」
```

可嘗試的方向：**平和 ↔ 自信之間**。

### 4. 情緒外顯度（Reserved ↔ Expressive）

```
壓抑：「這件事我不太想評論。」
平淡：「我覺得這件事還可以再討論。」
外顯：「我超不爽這件事！」
誇張：「我整個人都不好了！這什麼鬼！」
```

Threads 接受外顯，但要**真實**，不要表演。

### 5. 觀點立場度（Balanced ↔ Decisive）

```
平衡：「雙方都有道理，要看情境。」
偏向：「我比較傾向 A，但不否定 B。」
明確：「我選 A，這是我的立場。」
偏執：「只有蠢人才選 B。」
```

可嘗試的方向：**明確立場 + 留討論空間**。

## 4 種常見品牌人格範本

以下口吻是示意。第一人稱故事使用時須換成有依據的經歷，假設情節不能冒充真實經歷。

### 人格 1：誠實學長姊型

**適合**：教育、知識分享、職場帳號、行銷系、人資、創業者

**語氣定錨**：
- 距離感：親密 + 口語
- 銳利度：中立 + 偶爾銳利
- 自信度：平和 + 自信
- 情緒外顯度：平淡 + 偶爾外顯
- 立場度：明確立場

**範例口吻**：
```
「老實說，行銷系最該學的不是創意，
是把抽象變具體的能力。

我大三才搞懂這件事。
你呢，搞懂了沒？」
```

**用詞偏好**：
- 老實說、其實、我自己也、欸、我跟你說
- 不用：學術語言、官方公告語氣

---

### 人格 2：街頭吐槽型

**適合**：年輕品牌、休閒餐飲、運動、潮流、街頭文化

**語氣定錨**：
- 距離感：口語 + 廢話
- 銳利度：銳利
- 自信度：自信 + 偶爾高傲（角色設定）
- 情緒外顯度：外顯
- 立場度：明確

**範例口吻**：
```
「跟你說一個秘密：
慣老闆永遠不會跟你開誠布公。

他們只會說『我們公司是大家庭』
然後叫你假日上班。」
```

**用詞偏好**：
- 跟你說、欸幹、真的、笑死、誰啊
- 不避諱：黑色幽默、自嘲、白眼

⚠️ 但不能變成「酸民人格」，要有觀點。

---

### 人格 3：溫暖陪伴型

**適合**：療癒、家庭、寵物、心理健康、生活風格、咖啡店

**語氣定錨**：
- 距離感：親密
- 銳利度：柔和 + 中立
- 自信度：謙遜 + 平和
- 情緒外顯度：外顯（但溫暖型）
- 立場度：平衡 + 偏向

**範例口吻**：
```
「凌晨兩點，我媽傳訊息：
『冰箱有湯，記得熱。』

她不會說想我，
但她記得我愛喝湯。

每個說『不要擔心』的人，
都在用自己的方式擔心。」
```

**用詞偏好**：
- 也許、其實、我想、那種感覺
- 多用比喻、留白、慢節奏

---

### 人格 4：專業權威型

**適合**：B2B 服務、顧問、投資、財經、科技

**語氣定錨**：
- 距離感：親密 + 口語（避免冰冷）
- 銳利度：中立 + 銳利
- 自信度：自信
- 情緒外顯度：平淡（克制）
- 立場度：明確（用數據撐）

**範例口吻**：
```
「AI 會不會取代行銷？

我的看法：
與其只問會不會被取代，
不如看一項工作裡，哪些步驟能交給 AI，
哪些判斷仍需要你負責。

拿同一份文案試一次，
記錄 AI 幫你省下什麼、又有哪些地方要重做。
這比空泛的焦慮更能幫你決定下一步。」
```

**用詞偏好**：
- 我的答案、實際數據、根據觀察、結論
- 用數字、案例、引述，建立可信度

## 建立你的品牌語氣 SOP

### 步驟 1：用形容詞定義品牌人格

先用少數能區分品牌的形容詞定錨，以下以 3 個示範：

```
範例：
北市大行銷系 → 誠實的、有點壞的、社群感的
某咖啡品牌   → 溫暖的、慵懶的、文青的
某運動品牌   → 直接的、有挑戰性的、年輕的
```

### 步驟 2：寫品牌的「敵人」

明確說出**不是什麼**，比說「是什麼」更精準：

```
範例：
北市大行銷系 不是：高高在上的、官方公告式的、保守的
某咖啡品牌   不是：商業的、冷漠的、過度精緻的
```

### 步驟 3：定義常用詞 / 禁用詞

每個品牌都有自己的「術語」和「禁忌詞」。

**範例（北市大行銷系）**：
```
常用詞：
- 「老實說」「其實」「我們都」
- 「行銷不是 X，是 Y」（標誌句型）
- 「你有沒有發現...」
- 表情符號：適量用，但不要超過 2 個 / 篇

禁用詞 / 避用：
- 「敬請」「特此」「謹此」（官方語）
- 「乾貨」「劃重點」「滿滿的」（業配感）
- 過度的「！！！」「？？？」
- 「家人們」（中國風用語，台灣不吃）
```

### 步驟 4：寫一份「語氣對照表」

```
情境：要請大家留言
❌「請於下方留言給予回饋」
❌「歡迎大家留言」
✅「你也是嗎？留言給我看」
✅「我準備好被罵了，下面開戰吧」

情境：要分享觀點
❌「謹此分享個人淺見」
❌「以下分享我的看法」
✅「老實說，我覺得...」
✅「跟你說一個你可能不愛聽的」
```

### 步驟 5：建立「靈感倉」

把你看到的好句子、好 Hook、好留言收集起來。**這不是抄襲庫**，是讓你的語氣不斷對齊的素材。

工具：Notion / Apple Notes / NotebookLM。

## 一致性測試

每篇貼文發出前，跑這個檢查：

```
□ 這篇貼文的語氣，跟我上一篇貼文一致嗎？
□ 用詞風格符合我設定的「常用詞 / 禁用詞」嗎？
□ 如果讀者沒看到我的帳號名，能猜出是我嗎？
□ 跟我設定的品牌形容詞符合嗎？
```

若辨識度不足，檢查是否缺少品牌特有的觀點或句型，不必為追求辨識度扭曲內容。

## 提供語氣資料並用於寫作

建立或調整品牌語氣時，整理下列資料，供後續寫作與一致性檢查使用。已有品牌資料就沿用，不必每篇重建或要求使用者貼固定指令。

- 品牌名稱與人格形容詞。
- 不希望呈現的形象與原因。
- 具體受眾、發布平台及本次主題。
- 常用句型、禁用詞與可辨識的例稿。
- 本次情境需要的語氣變化，例如公告、回覆或故事。

寫作時從例稿辨認用字、節奏與觀點，再套用到新材料；完成後對照上方一致性測試。資料有缺口時依既有內容提出暫定方向，不把想像當成已確認的品牌設定。

## 常見錯誤

❌ **學別人語氣**：抄到一半變四不像。
✅ **找到自己的語氣**：哪怕粗糙，先有再說。

❌ **每篇換語氣**：「今天可愛、明天嚴肅、後天搞笑」 → 讀者搞不清你是誰。
✅ **核心語氣一致，依情境變化**：核心語氣穩定，偶爾延伸。

❌ **用官方語氣假裝親民**：「親愛的粉絲們」「我們團隊」這種詞會立刻拉開距離。
✅ **用第一人稱 / 對話口吻**：「我」「我們」「你」「老實說」。

❌ **怕失誤就什麼都不講**：結果發的都是無腦正能量。
✅ **明確立場 + 留討論空間**：你可以強硬，但要邀請對話。
