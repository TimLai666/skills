# 10｜避雷清單｜常見死法

> 用讀者反應檢查寫法，區分內容問題與尚待觀察的成效。

## 11 種常見寫作與經營問題

### 1. ❌ Hook 是介紹語

**待改善範例**：
```
今天想跟大家分享行銷系的學習心得
讓我們一起來看看
```

**可能的問題**：
- 開頭只介紹接下來要做什麼，還沒讓讀者看到值得讀的內容。

**怎麼救**：
```
✅「行銷系第一年，我以為要學的是創意。
   結果學的是怎麼跟組員溝通。」
```

直接把觀點當 Hook。

---

### 2. ❌ 內容像 LinkedIn

**待改善範例**：
```
身為一位行銷系學生，我認為品牌應當建立差異化的溝通策略，
透過深度洞察消費者行為，創造價值共鳴。
```

**可能的問題**：
- 若目的是日常交流，履歷口吻容易和讀者產生距離
- 太多書面語、抽象名詞、長句

**怎麼救**：
- 刪掉沒有實際作用的書面套語，必要用詞照內容保留
- 用人話：「我覺得」「我發現」「老實說」

---

### 3. ❌ 太多 Hashtag

**待改善範例**：
```
[正文]
#行銷 #品牌 #大學生 #北市大 #社群 #創意 #職場 #學習 #成長
```

**可能的問題**：
- 正文堆滿標籤會干擾閱讀。可用標籤數量以當前介面或官方說明為準。

**怎麼救**：
- 挑與內容相關的標籤，不為湊數加入
- 或完全不用

---

### 4. ❌ 只丟連結，沒交代用途

**待改善範例**：
```
完整內容看這 → https://medium.com/...
```

**可能的問題**：
- 沒說明連結的用途，讀者缺少點擊理由。外連是否降權不能憑推測判定。

**怎麼救**：
- 說明點開會看到什麼，依閱讀與轉換目的放在主文或補充留言。
- 查證來源或購買入口要容易找到，不為躲避未證實的降權要求讀者私訊。

---

### 5. ❌ 一篇講三件事

**待改善範例**：
```
今天想聊三件事：
1. 行銷系是什麼
2. 我為什麼選這個系
3. 給高中生的建議

[然後每件事各 100 字]
```

**可能的問題**：
- 多個題目缺乏共同主線，容易稀釋重點
- 讀者抓不到「這篇在講什麼」就走

**怎麼救**：
- 找出共同主線重新組織，或拆篇處理。
- 與主旨無關的內容再刪掉。

---

### 6. ❌ 純自吹自擂

**待改善範例**：
```
我們的服務已經幫超過 1000 位客戶解決問題！
立刻聯絡我們了解更多 👉 [連結]
```

**可能的問題**：
- 只講自己多好，沒讓讀者看見具體用途或可信的依據
- 完全沒有 hook、沒有觀點、沒有對話

**怎麼救**：
- 把成功案例變成**故事**
- 可從「你可能遇過……」切入，只有確有經驗才寫「我也遇過」。
- 用「客戶說的話」當 hook，而不是「我們的優勢」

---

### 7. ❌ 想要討論，卻沒提供可回應的內容

**待改善範例**：
```
[一段很好的觀點]
[結束]
```

**可能的問題**：
- 目標是交流時，讀者需要有可分享的經驗或可回應的立場。公告、資訊或完整觀點不必強加問句。

**怎麼救**：
- 結尾留問題：「你覺得呢？」「你會選哪個？」
- 結尾留爭議：「我準備好被罵了」
- 結尾留共鳴：「你也是嗎？」

---

### 8. ❌ 標題黨但內容空

**待改善範例**：
```
【震驚】這個秘密竟然沒人告訴你！
[然後內容很乾]
```

**可能的問題**：
- 開頭承諾與內文不符，可能降低讀者信任與後續閱讀意願。

**怎麼救**：
- Hook 強，但**內容也要對得起 Hook**
- 事實與承諾要有依據，避免讓讀者因落差感到受騙。

---

### 9. ❌ 長文密集，缺少閱讀節奏

**待改善範例**：
```
[450 字滿滿的文字，密密麻麻沒有分段]
```

**可能的問題**：
- 手機上的密集長段落增加閱讀負擔，讀者較難抓到重點。

**怎麼救**：
- 150–350 字可作短文起點，完整論述需要更多篇幅時不硬刪
- 多分段、多空行
- 短句、口語化
- 真的需要長 → 拆成串文

---

### 10. ❌ 在錯時段發

**待改善範例**：
```
假設活動是週一早上截止，
卻到週日深夜才發出需要讀者準備資料的公告。
```

**可能的問題**：
- 沒確認目標受眾的活躍時間，可能錯過需要即時回應的情境。

**怎麼救**：
- 參考 [發文時間策略](06-posting-timing.md)，用自己的帳號測試候選時段
- 不能立即發 → 用排程

---

### 11. ❌ 發了就閃

**待改善範例**：
```text
貼文邀請大家提問，
讀者提出具體問題後，帳號一直沒有答覆。
```

**可能的問題**：
- 讀者期待落空，問題無人處理，也失去了解需求的機會。

**怎麼救**：
- 依人力安排回覆時間，優先處理問題與有價值的討論。
- 活動與即時問答先確認有人能回應，不設每篇 15 分鐘內逐則回覆的要求。

---

## 容易擴大爭議的題材

依品牌目標、受眾與具體內容判斷，不另做道德評分。爭議、焦慮與衝突可以服務表達，但要看吸引來的討論是否有助目標，以及實際反效果。

- **政治議題**：檢查與品牌的關聯、立場是否清楚，以及是否願意處理隨後的論辯。不把所有政治內容一律排除。
- **性別、種族、性向與群體嘲諷**：檢查概括是否有依據，笑點針對什麼，以及被截圖脫離脈絡後可能引發的反應。衝突帶來的互動未必能轉成品牌認同。
- **醫療、法律等專業內容**：查核具體主張與適用條件，區分一般資訊與對個人的建議。不能以一句免責聲明替代內容正確性。
- **商業資訊與私人經歷**：確認哪些資料可以公開。使用客戶、前公司或私下對話時，留意未公開資訊與可識別當事人的細節。

## 業配 / 廣告貼文避雷

以下為寫法示例。實際使用須依作者經驗與產品資料改寫，合作揭露依適用要求處理。

### ❌ 業配寫法

```
推薦這款新出的咖啡豆！
真的超好喝！
立刻購買 👉 [連結]
#業配 #咖啡 #推薦
```

**可能的問題**：
- 只有推薦與催買，缺少具體感受或選擇理由
- 「真的超好喝」是業配文標準句

### ✅ 業配寫法

```
最近喝到一款豆子，
打破我「中焙才有層次」的偏見。

它是淺焙，
但喝起來像一首寫得很慢的詩。

我之前都不買淺焙，
因為怕「酸」這個字。
這款讓我重新理解，
酸不是缺點，是骨架。

[品牌名] 的 [產品名]，
最近在喝。

你有喝到讓你「打破偏見」的豆子嗎？
```

**改善之處**：
- 用故事 / 觀點包裝產品
- 觀點是真的（即使有業配，觀點要真實）
- 結尾留討論空間

## 「補救」清單：發了之後發現不對怎麼辦

### 狀況 1：初期沒有互動

- 依既定觀察期間查看，不先判定失敗。
- 有真正值得補充的內容時再自留言，不靠固定留言數搶救。
- 比較題材、開頭、曝光與時段，作為下一篇調整依據。

### 狀況 2：發完發現有錯字

查看當前介面是否允許編輯，以及官方說明的限制。能編輯就修正，不能編輯時依影響選擇留言更正或刪除重發。刪除重發會失去原貼文及其互動，需權衡錯誤影響。

### 狀況 3：發完發現觀點不對 / 引起反彈

- 先判斷是事實錯誤、表達誤會或立場不同，再決定修正、補充或刪除。
- 補一則貼文 + 留言區回應
- 道歉要明確（不要「如果造成困擾」這種公關式語法）

### 狀況 4：意外爆紅了

- 把握流量：發第二則延伸貼文
- 在留言區跟讀者深度對話
- 延伸內容要符合這次吸引讀者的原因，突然推銷無關產品可能使新讀者流失。
- 順勢介紹品牌：把個人頁簡介 / pinned post 準備好

---

## 發布前的最後檢查

看這篇是否給目標讀者具體的觀點、資訊或感受，開頭與內文是否相符。成效不佳時檢查實際內容與數據，不用「不真誠」或「演算法懲罰」代替分析。
