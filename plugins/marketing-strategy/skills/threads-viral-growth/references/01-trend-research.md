# 01｜趨勢研究 SOP

> 寫新稿或改既有材料前，先看同類內容怎麼寫、讀者怎麼回應，再選擇自己的角度。

## 核心原則

四種來源都要查，包括已提供材料的改寫。即時話題查當下狀態，常青題材則比較仍相關的內容，不把所有題材都當成追梗。研究有兩個目的：

1. **找熱題**：找出當下哪個話題討論度高，可以順勢進去。
2. **找冷感點**：找出哪些觀點還沒人講、講過但沒講清楚、或大家都講錯了。藉此找出內容可增加的觀點。

## 四種必查來源

依下列順序檢查，四類都要有實際結果。一般社群文案也保留這四類研究，並在同類帳號與跨平台研究中納入目標平台。不能把 Threads 的觀察直接當成其他平台的規律。

### 1️⃣ Threads 平台內趨勢話題（一手）

**操作**：
- 使用當前可用的搜尋、趨勢入口或相關討論串，確認地區、語言與受眾。
- 閱讀原貼文與留言，不只看熱門標示或 AI 摘要。
- 若帳號或地區沒有趨勢榜，查相關討論並說明這是觀察樣本，不是全台排行榜。

**判讀**：
- 看話題是「正在升溫」還是「已經退燒」
- 看討論串的情緒主調是什麼（憤怒、嘲笑、惋惜、好奇？）
- 對照讚數、留言數與留言內容，分辨討論來自共鳴、疑問還是爭執，不用固定比例判定品質。

**注意**：記錄原文連結、發布與查閱時間。功能與介面以實際看到的內容為準。

### 2️⃣ 網路搜尋相關話題

**查詢公式**：
```
Threads 熱門 [TA 圈層詞] [近一個月]
Threads 爆紅 [產業/主題]
[品牌名/品類] threads 討論
[時事關鍵字] threads 留言
```

**查詢示例**（假設是行銷系招生任務，年份依任務更新）：
- `Threads 熱門 大學生 選系`
- `Threads 熱門 高中生 學測`
- `Threads 行銷系 討論`
- `2026 大學申請 ptt dcard`

**判讀重點**：
- 比對新聞與社群原文的日期、討論量與角度，判斷是否有尚未說清楚的切入點。
- 看 PTT/Dcard 有沒有爆文跑出來，能不能延伸成 Threads 角度

### 3️⃣ 競品 / 同類帳號最近爆文

**操作步驟**：
1. 找同性質的帳號（同產業、同 TA、同調性），以能比較不同寫法為準，不固定帳號數。
2. 優先看近期貼文，例如最近 7 天；發布頻率低或常青主題可延長期間並記錄。
3. 對照同帳號的一般與高互動貼文。例如平常約 50 讚、某篇 500 讚是值得追查的差異，不足以證明某個句型造成成功。
4. 拆解：
   - Hook 是什麼？哪種類型？
   - 主導情緒是什麼？
   - 留言區大家在聊什麼？
   - 哪些寫法有幫助、哪些引起誤解？我們的材料能補什麼？

**重要**：
- 不是抄，是學「結構」與「情緒設計」
- 理解受眾需求與結構，不直接抄別人的句子或經歷，也不因曾經熱門就一律排除題材。

### 4️⃣ 跨平台時事 / 訊號

**可選入口**（依主題選擇，不要求下列每個網站都查；跨平台這一類本身不可省略）：
- PTT 與主題相關的看板
- Dcard 熱門
- 新聞頭條
- YouTube 趨勢 / TikTok 熱門短影音
- Google 搜尋趨勢（Google Trends）

**用途**：
- 找尚未被 Threads 大量討論、但有機會延伸的話題
- 比較各平台的討論時間、受眾與反應，不預設固定的傳播順序或提前時數。

## 完成判斷與研究記錄

不固定研究分鐘數，也不以搜尋次數驗收。每類都要有可核對的內容或確實查無相關結果的紀錄，研究結果須能支持切角與寫法的比較。

- 搜尋結果用來找到原文。平台、同類帳號的研究須實際閱讀貼文與留言，不能只依摘要推斷反應。
- 同一來源可提供不同觀察，但不能把同一段摘要重複填四次當成四類皆完成。
- 登入、工具或存取受阻時，嘗試其他可用入口或請使用者補充原文。尚未取得的來源標為缺口，不算已查完。
- 來源受阻時先整理已知材料、待查問題與已完成的研究，缺口補齊後再成稿。
- 研究完成後可接續寫作，摘要與成稿一起交付，不另設固定等待確認的關卡。

精簡記錄可用下表；深入研究時在各來源下展開貼文拆解與比較，不硬湊話題或候選角度。

| 來源類別 | 原文連結、日期與查閱範圍 | 實際觀察或缺口 | 對寫法的影響 |
| --- | --- | --- | --- |
| Threads 平台討論 | | | |
| 網路搜尋 | | | |
| 競品／同類帳號 | | | |
| 跨平台時事與討論 | | | |

研究結論說清楚：哪些題材與受眾相關、哪些結構值得借鏡、哪些觀點可挑戰，以及我們能增加什麼。無法從樣本確認的趨勢，標成觀察或待測方向。

## 進階：建立你的趨勢監測習慣

如果使用者是要長期經營（不是單次任務），建議：

- **日常觀察**：看 Threads 相關討論與同類帳號的新貼文。
- **定期彙整**：整理值得借鏡的寫法與下期題材，頻率依經營需求安排。
- **建立你的「靈感倉」**：用 Notes / Notion / NotebookLM 收集（截圖 + 一句話備註）

長期下來，這個倉會變成你的「不用想題目就有題目」資產。

## 常見錯誤

❌ 看到一個熱話題就直接寫貼文。沒分析切角，會變成「跟風文」。
❌ 把過去的熱門當成現在的熱門，沒有確認它是否仍相關。
❌ 只看自己同溫層的爆文。會被困在 echo chamber。
❌ 照搬別人的情節與句型，沒有連結到自己的主體與材料。

✅ 看趨勢但要找到自己的角度。
✅ 趨勢只用骨架，肉一定要自己長。
✅ 寧可錯過趨勢，不要硬蹭錯不相干的話題（會傷品牌信任）。
