# 05｜情緒設計框架

> 情緒可幫助讀者理解內容的意義。依品牌目標、受眾與材料決定情緒走向，不以刺激強度作唯一標準。

## 情緒與分享意願

Berger 與 Milkman 的〈[What Makes Online Content Viral?](https://doi.org/10.1509/jmr.10.0353)〉（2012）以《紐約時報》文章及實驗研究情緒與分享。研究指出，除了正負情緒，喚起強度也有關：敬畏、憤怒、焦慮等高喚起情緒較容易伴隨分享，悲傷等低喚起情緒則較少。這是內容傳播的研究，不是 Threads 演算法權重。

| 分析角度 | 如何用於寫作 |
| --- | --- |
| 情緒正負 | 讀者感到愉快、不滿或擔心，這與品牌想表達的立場是否一致？ |
| 喚起強度 | 內容使讀者想採取行動、與人討論，還是安靜體會？例如憤怒與悲傷都偏負向，但行動傾向不同。 |
| 受眾與場景 | 同一段文字對不同讀者可能引起不同反應，要與研究中的留言和實際目標對照。 |

情緒設計要看讀者是否有理由回應或分享，例如被理解、想與朋友討論、獲得實用資訊。強烈情緒與平靜語氣都有適用情境，不能據此保證擴散成效。

以下是六種可運用的情緒與假設例句。它們不是勝率排名；第一人稱情節、數據及具體威脅使用前須有依據，假設案例不能冒充真實經歷。

## 六大主導情緒

### 1. 共鳴（同感、被理解）

**可觀察的反應**：留言「+1」「就是我」「真的」+ 轉發給朋友

**最強場景**：TA 的日常痛點、生活中的小無奈、不被理解的時刻

**怎麼寫**：
- 寫出**具體場景**，越具體越打人
- 用「我們」「你」「大家」第二/第一人稱，不要「他們」
- 需要邀請討論時，結尾可用「你也是嗎？」的問句

**範例**：
> 「我們都在裝自己沒事，
> 然後在凌晨三點傳訊息給不該傳的人。
> 你最近一次傳是什麼時候？」


---

### 2. 憤怒（不爽、不公、雙標）

**可觀察的反應**：引用 + 長留言、罵留言、引發辯論

**最強場景**：社會亂象、職場雙標、被當盤子、體制問題

**怎麼寫**：
- 鎖定**明確的對象/現象**（不是空泛抱怨）
- 用堅定但不失邏輯的句式
- 不要寫到失控，要有「白眼」的味道，不是「咆哮」

**範例**：
> 「『我們是一個大家庭』
> 是慣老闆說過最不要臉的一句話。
> 家人不會叫你免費加班。」


**⚠️ 注意**：憤怒型容易失控。寫完再讀一次，把任何讓你後悔的詞砍掉。

---

### 3. 幽默（自嘲、白眼、產業內梗）

**可觀察的反應**：截圖傳給朋友、轉發、留言一起笑

**最強場景**：產業內笑話、自嘲、社會觀察、生活吐槽

**怎麼寫**：
- 幽默的核心是**反差**（預期 vs 現實）
- 依品牌人格選擇自嘲或嘲諷，判斷笑點是否易被誤解、是否讓目標受眾疏離
- 不要解釋笑點，留白讓讀者自己領會

**範例**：
> 「老闆說『下班就下班』的時候，
> 你就知道今天要加班了。」


**⚠️ 注意**：幽默有文化差異。可比較同類帳號如何使用白眼幽默、自嘲與諧音梗，觀察目標受眾的實際反應。

---

### 4. 驚訝（反差、冷知識、沒想到）

**可觀察的反應**：留言「真假」「我不知道」「沒想到」+ 收藏 + 分享

**最強場景**：冷知識、反差體悟、業界內幕、數據驚奇

**怎麼寫**：
- 前半句設「合理預期」，後半句用「但其實…」翻盤
- 給一個具體**數字/事實**讓人記住
- 需要邀請討論時，結尾可用「你知道嗎？」/「你以為呢？」

**範例**：
> 「我以為長大會有答案，
> 27 歲才發現只有更多問題，
> 而且每個問題都比上一個更難。」


---

### 5. 焦慮（落後、稀缺、不確定）

**可觀察的反應**：收藏（怕忘）、轉發給同處境的人、留言問細節

**最強場景**：競爭話題、限時、AI 時代焦慮、世代焦慮

**怎麼寫**：
- 點出**具體威脅**（不是泛泛的「現在很競爭」）
- 給一個**參考標準**（讓人對照自己有沒有落後）
- 結尾不要太絕望，要留一條出路

**範例**：
> 「看到同學分享 AI 練習成果，
> 而你還在猶豫要不要付 ChatGPT 的訂閱。
> 與其一直擔心被取代，不如先試著用 AI 完成一個手邊任務。
> 從哪一個 prompt 開始學起？」


**⚠️ 注意**：焦慮訴求需檢查威脅、稀缺與承諾的依據，也要評估是否使讀者無力、反感或降低信任；可搭配可行的下一步。

---

### 6. 溫暖（被理解、被支持、被看見）

**可觀察的反應**：分享給朋友、留言感謝、追蹤帳號

**最強場景**：故事型貼文、節慶、紀念日、人物特寫

**怎麼寫**：
- 用**具體人物 + 場景**，不要泛泛說溫暖
- 不要硬煽情，**輕輕地**比重重地更打人
- 需要邀請討論時，結尾可用「你也曾經…嗎？」

**範例**：
> 「凌晨兩點，我媽傳訊息：
> 『冰箱有湯，記得熱。』
>
> 她不會說想你，但她會記得你愛喝湯。」

## 情緒選擇決策樹

```
你的目標是什麼？
├── 想讓讀者代入       → 共鳴 / 幽默
├── 想邀請立場討論       → 爭議（憤怒衍生）/ 反問
├── 想要漲粉           → 溫暖（故事型）/ 共鳴
├── 想要強記憶         → 驚訝 / 反差
├── 想要轉換行動       → 焦慮（搭配解方）
└── 想要分享傳染       → 幽默 / 共鳴
```

---

## 讓情緒有清楚的走向

可用一個主導情緒聚焦，也可讓情緒隨故事自然轉折。不限制情緒數量或比例，重點是讀者能理解轉折。

1. 先確定希望讀者讀完留下什麼感受或理解。
2. 讓 Hook、情境與觀點支持這個方向。
3. 混合情緒時檢查轉折是否有材料支撐，避免互相打斷。
4. 按內容選擇收束、留白或邀請討論，不必每篇加問句。

---

## 情緒強度檢核（寫完跑一次）

讀完整篇貼文，閉上眼睛問自己：

```
□ 讀完留下什麼感受或理解，是否符合目標？
□ 情緒強度是否適合內容目標與品牌語氣？
□ 情緒轉折是否清楚、有材料支撐？
□ 結尾有沒有把情緒收回 / 留討論空間？
```

若情緒或資訊效果未達目標，先找出失效的段落再調整，不必整篇重寫。

## 進階：情緒節奏

長一點的貼文（200+ 字）可以設計「情緒節奏」：

```
情緒節奏範例：
─────────────
第 1 段：吐槽 / 帶點憤怒        ← Hook，先抓住人
第 2 段：共鳴 / 場景鋪陳        ← 讓 TA 代入
第 3 段：轉折 / 帶一點驚訝      ← 製造記憶點
第 4 段：留言鉤 / 邀請對話      ← 收尾
```

需要故事轉折或較長鋪陳時可用這個節奏；資訊型內容也可以平穩清楚地呈現。

## 品牌適用性與實際反效果

| 情緒 | 使用前判斷 |
|---|---|
| 共鳴 | 描述是否貼近受眾，而非把少數經驗當成所有人的處境 |
| 幽默 | 笑點與品牌人格是否相符，會否讓目標受眾疏離 |
| 溫暖 | 情節是否有依據，情感鋪陳是否自然 |
| 驚訝 | 數字、反差與承諾是否有依據 |
| 焦慮 | 威脅或稀缺是否真實，是否讓讀者失去信任或無法行動 |
| 憤怒 | 對象、理由與品牌禁區是否清楚，討論會否偏離目標 |

## 給品牌帳號的特別提醒

不預先為情緒分級或規定使用比例。依品牌人格、目標、同類內容研究與帳號實際反應決定組合。

關鍵是找到品牌**人格**對應的情緒組合。例如：
- 「正能量 / 教育」品牌 → 共鳴 + 溫暖 + 偶爾驚訝
- 「叛逆 / 街頭」品牌 → 幽默 + 憤怒 + 爭議
- 「專業 / 諮詢」品牌 → 驚訝（行業洞察）+ 焦慮（搭配解方）
- 「年輕 / 校園」品牌 → 共鳴 + 幽默 + 反差
