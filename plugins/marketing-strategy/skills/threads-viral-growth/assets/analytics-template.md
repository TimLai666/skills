# 數據追蹤模板

> 在成效分析或持續經營時使用。記錄實際可取得的數據，搭配留言內容比較，不把單篇結果當成固定規律。

## 指標與比較口徑

- Views 記為瀏覽次數，不直接當作不重複的觸及人數。平台若另有 Reach，分開記錄。
- 留言率 = 留言數 ÷ 指定分母 × 100%；互動率 = 選定互動項目合計 ÷ 指定分母 × 100%。分母可用瀏覽次數或觸及人數，但比較時須一致。
- 註明留言是否包含作者回覆，轉發、引用與分享是否為不同欄位，避免重複加總。資料未提供就留作未取得，不填零；分母為零不計算比率。
- 記錄觀察期間，例如發布後48小時。依任務調整，但比較貼文須使用相同期間。週月彙總註明是逐篇比率平均或總互動除以總分母。
- 以任務目標設定指標：討論看留言內容與留言率，導流看連結點擊，漲粉看新增追蹤。目標值依帳號資料設定，不套固定門檻。
- 比較時一併看題材、發布時間、粉絲規模及付費曝光等差異。樣本少時先提出待測方向，不把相關性當作原因。

## 階段回顧

累積足以比較的資料後，整理高低表現貼文的共同特徵；以下排名與公式是整理線索的示例，不是樣本數門檻或成效保證。

### 我的爆文 DNA（前 10 大表現最好的貼文）

```
排名 | Hook 類型 | 結構 | 情緒 | 主題 | 時段 | 瀏覽次數
1.   |          |     |      |     |     |
2.   |          |     |      |     |     |
3.   |          |     |      |     |     |
4.   |          |     |      |     |     |
5.   |          |     |      |     |     |
...
```

找出**共同特徵**：

```
值得再測試的組合 =
  [最常出現的 Hook 類型] × 
  [最常出現的結構] × 
  [最常出現的情緒] × 
  [最常出現的時段]
```

### 我的爛文 DNA（前 10 大表現最差的）

```
排名 | Hook 類型 | 結構 | 情緒 | 主題 | 時段 | 瀏覽次數
1.   |          |     |      |     |     |
2.   |          |     |      |     |     |
...
```

找出需要再驗證的組合與可能原因，不只看最高與最低幾篇就永久排除方向。

## 取得資料與回顧

從當前平台的 Insights 或使用者提供的分析匯出取得資料，欄位依實際可見內容確認。第三方工具可能使用不同定義，合併前先核對。

回顧時比較多篇內容、留言在討論什麼，以及是否達成原先目標。高瀏覽不一定帶來追蹤或導流，低留言也不直接證明內容失敗。觀察後選擇值得再測試的題材、開頭或時段，不同時改所有條件。
